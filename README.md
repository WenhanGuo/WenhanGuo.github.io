# Personal academic profile

A dependency-free, responsive personal profile site. Replace every `Your Name`, `[placeholder]`, and `your-...-username` value in `index.html`, then add a real CV at `assets/cv.pdf` (or change that link).

## Publish with GitHub Pages

1. Create an empty repository on GitHub, for example `your-github-username.github.io` for a personal site or `personal-website` for a project site.
2. In this folder, run:

   ```bash
   git init
   git add .
   git commit -m "Initial personal site"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   git push -u origin main
   ```

3. On GitHub, open the repository’s **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`, and save.
4. GitHub will publish it at `https://YOUR-USERNAME.github.io` for the specially named `YOUR-USERNAME.github.io` repository, or at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` for any other repository.

It can take a couple of minutes for the first deployment. Subsequent pushes to `main` publish automatically.
